# Started this project a week before my university studies begin to keep track of my budget.
In the app you can: 
- Enter incomes and expenses. 
  - The app then automatically calculates remaining budget and how much of the budget has been used (%).
- Toggle between two themes: light (set as default theme) and dark.
  - Toggle button locates in the upper left corner.
- Check app usage info.
  - On the upper right corner is an info button which open "Usage info" window. There you can check the current version along with session total time used.
 
# Very light application
- Saves data only when you write something e.g. "100€, groceries" to the entry field and press enter.
- Saves settings e.g. selected year and month when changed. Also selected theme is saved to settings file after theme button is first pressed.
- Saves session seconds to total_time.txt before closing the app.
- Every file is once more written before app shuts down.
- Every file is almost nonexistent .csv file due to the size of them.
